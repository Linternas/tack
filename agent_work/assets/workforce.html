직원 설정

지침과 스킬은 권한을 확대하지 않습니다. 변경된 직원 설정으로 구현하려면 기존 업무 범위를 다시 승인해야 합니다.

실행 모드와 프로젝트 권한

프로젝트 권한 · 실행 모드와 별도
자동 승인할 검증 명령

예: [["python3","-m","unittest"],["pnpm","test"]]. 목록 밖 명령은 계획을 직접 승인해야 합니다. 직접 실행하는 검증 명령은 신뢰할 수 있는 명령만 허용하세요.

Git·푸시·배포·결제·외부 계정 변경은 자동 허용하지 않습니다. 모드·권한 확대는 새 목표부터 적용되며, 권한 축소는 기존 목표에도 적용됩니다. 보호 경로는 결과 통합 시 검사합니다.

응답 종료 시 집계하므로 한 응답에서 토큰 한도를 넘을 수 있습니다. 한 번에 최대 100회 협업을 진행하며 모델은 처리 가능한 업무가 있을 때만 호출합니다. 큐와 대기는 브라우저를 닫아도 유지됩니다.

한도는 다음 실행부터 적용됩니다.

이 목표의 위임 승인

직원은 여기서 승인한 요구사항·역할·파일·검증 범위 안에서만 변경 업무를 주고받습니다. 새 기능, 호환성을 깨는 계약 변경, 외부 부작용과 최종 완료는 별도 사용자 승인이 필요합니다.

승인 유효 시간은 대기 시간을 포함합니다. 팀 한도보다 넓게 위임할 수 없습니다. 토큰은 응답 종료 후 수집되므로 진행 중 응답에서 한도를 넘을 수 있습니다. 승인 후 준비된 업무는 실행 큐로 전달됩니다.
